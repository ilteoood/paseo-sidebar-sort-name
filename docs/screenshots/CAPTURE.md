# Screenshot checklist

Capture with the macOS screenshot tool (`Cmd+Shift+4` for a region) and save into this directory under the exact filenames below.

## `sidebar-sorted.png`

- Must show: the sidebar with the Sorted sidebar view selected, one project expanded, its workspaces listed underneath, and at least two projects so the grouping is visible. Default preferences (sort by name, group by project, title source title).
- Suggested window state: desktop app on a host with several projects and workspaces, sidebar wide enough that no title is truncated, no menu open, nothing hovered.

## `grouped-by-status.png`

- Must show: the same host with grouping set to Status, so the status headers with their icons and counts are visible, and at least two status groups populated.
- Suggested window state: same window size as the previous shot, no menu open, at least one group left expanded.

## `display-menu.png`

- Must show: the floating display menu opened from the settings button in the Workspaces header, showing the root page with Grouping, Sort, Title, Show, Project, and Show background. Anchor position of the menu relative to the header should be clear.
- Suggested window state: same window size, one project with workspaces behind the menu, cursor away from the rows so no hover tint distracts.
